# Cinema Ticket Booking And Management App

## Description
An Android application for booking and managing cinema tickets.

## Technologies
- Java
- Android Studio
- XML
- SQLite
- RecyclerView
- Material Components

## Features
- User registration and login
- User profile management
- Admin/User role-based access
- Movie management
- Account Management System
- Movie search
- Cinema ticket booking
- Ticket management

- Team Size: 2
- Role: Android Developer
